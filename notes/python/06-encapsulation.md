# 封装

`__init__`:初始化

`__eq__`:对象“相等”规则
```
def __eq__(self, other): return isinstance(other, 类名) and self.关键属性 == other.关键属性
```

`__str__`:给对象看的转义

`__repr__`:给自己看的转义

### super () 函数

- 调用父类的方法，最常用于初始化时复用父类逻辑
- 写法：`super().__init__(参数)`
- 比直接写父类名更规范，能更好地适配多重继承场景

- **单下划线 `_name`**

    - 编码约定，表示 “内部成员，不建议外部直接访问”
    - 无语法强制限制，仅作提示作用

- **双下划线 `__name`**

    - 触发**名称改写（name mangling）**，外部无法直接通过原名访问
    - 本质是自动改名（`_类名__属性名`），不是严格的私有访问控制
