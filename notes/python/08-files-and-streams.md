# 文件与流

| 模式  | 可读  | 可写  | 备注                               |
| --- | --- | --- | -------------------------------- |
| `r` | ✅   | ❌   | 默认模式，文件不存在抛出 `FileNotFoundError` |
| `w` | ❌   | ✅   | 文件不存在则创建，存在则**清空原有内容**           |
| `x` | ❌   | ✅   | 新建文件，文件已存在则直接报错                  |
| `a` | ❌   | ✅   | 追加模式，文件不存在则创建，存在则在末尾追加内容         |

- **readline(size)**

    - 读取一行内容，包含换行符；size 可限制最大读取字符数
    - 读到文件末尾时返回空字符串

- **readlines()**

    - 读取文件所有行，返回字符串列表，每个元素对应一行（带换行符）
    - 小文件适用，大文件会占用大量内存

- **writelines (字符串序列)**

    - 批量写入多行字符串
    - ❗ 注意：**不会自动添加换行符**，需手动在每行末尾加 `\n`
    - 没有单独的 `writeline` 方法，单行写入直接用 `write()` + 换行符

- **按行迭代（while 版）**：`while` 循环 + `readline()`，读到空行终止
- **一次性全量读取**：`read()` 或 `readlines()`，仅适合小文件
- **for 循环直接迭代文件对象（最高效，推荐）**
    ```
    with open("file.txt") as f:
        for line in f:
            print(line)
    ```
