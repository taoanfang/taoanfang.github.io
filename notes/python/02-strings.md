# 字符串

==字符串不可被修改==
普通字符串可以跨行，在这一行的最后一个字符之后加==“ / ”==

原始字符串以“ r ”开头：按照原始输出，不进行转译
字符串分割：split
字符串的连接：join

- `find(sub, start, end)`：查找子串，返回首个匹配左侧索引，无匹配返回 - 1；可指定查找区间`[start, end)`。
- `split(sep)`：按分隔符切割字符串为字符串列表；不传分隔符自动切割所有空白（空格、\n、\t），自动合并连续空白。
- `join(序列)`：分隔符.join (字符串序列)，拼接序列内所有字符串；序列只能存放字符串，数字会报错，是 split 的逆操作。
- 大小写转换

    - `lower()`：全部转为小写，适合忽略大小写校验；
    - `title()`：所有单词首字母大写；`string.capwords()`优化标题格式，处理缩写更自然。

- 清除首尾字符

    - `strip(字符)`：删除字符串两侧指定字符，默认清除空格；
    - `lstrip()`：仅删除左侧字符；`rstrip()`：仅删除右侧字符。

- `replace(old, new, count)`：全局替换匹配子串；count 参数限制仅替换前 count 个匹配项。
