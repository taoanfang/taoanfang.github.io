# 正则表达式、JSON 与 CSV

## 正则表达式

### 常用元字符

| 元字符  | 作用                             |
| ---- | ------------------------------ |
| `.`  | 匹配除换行符 `\n` 外的**任意单个字符**       |
| `\d` | 匹配任意数字，等价于 `[0-9]`             |
| `\w` | 匹配字母、数字、下划线，等价于 `[a-zA-Z0-9_]` |
| `\s` | 匹配所有空白字符（空格、制表符、换行等）           |
| `^`  | 匹配**字符串开头**位置                  |
| `$`  | 匹配**字符串结尾**位置                  |

### 量词

|量词|含义|
|---|---|
|`*`|字符出现 0 次 或 多次|
|`+`|字符出现 1 次 或 多次|
|`?`|字符出现 0 次 或 1 次|
|`{n}`|字符**恰好**出现 n 次|
|`{m,n}`|字符出现 m~n 次（逗号两侧无空格）|


### 字符集
- 作用：匹配括号内**任意一个字符**；
- 用法：`[abc]` 匹配 a/b/c、`[a-z]` 匹配小写字母、`[^abc]` 匹配**非**a/b/c 的字符；
- 特性：字符集内 `.` `*` `+` 等元字符会失去特殊含义，仅作为普通字符。

### 分组和捕获
- 圆括号 `()` 实现分组捕获，分组按左括号顺序编号；`group(0)` 代表**整个匹配结果**，`group(1)`/`group(2)` 代表第 1/2 个分组；
- 用途：拆分结构化文本（如日期 `(\d{4})-(\d{2})-(\d{2})` 拆分年、月、日）；
- 反向引用：替换 / 匹配时用 `\数字` 引用分组内容，如 `\1` 代表第一个分组。

### 选择符与转义字符
- 选择符 `|`：逻辑 “或”，匹配 `|` 左右任意一个表达式；
- 转义字符 `\`：若需要匹配 `.` `*` `(` `[` 等**特殊符号本身**，必须加反斜杠转义，如 `\.` 匹配小数点。


## re常用核心函数

- **`re.match(规则, 字符串)`**：仅从**字符串开头**匹配，匹配失败返回空；
- **`re.search(规则, 字符串)`**：遍历整个字符串，查找**第一个**匹配项；
- **`re.findall(规则, 字符串)`**：查找**所有**匹配项，返回列表（文本提取最常用）；
- **`re.sub(规则, 新内容, 字符串)`**：按照规则**替换**文本内容；
- **`re.split(规则, 字符串)`**：按照正则规则**分割**字符串。


## JSON
|JSON 类型|对应 Python 类型|
|---|---|
|对象 (object)|字典 (dict)|
|数组 (array)|列表 (list)|
|字符串 (string)|字符串 (str)|
|数字 (number)|整型 (int) / 浮点型 (float)|

###  json 模块四大核心方法
- **`json.loads(json字符串)`**
    data = json.loads(text)
    功能：将**JSON 字符串**转为 Python 对象（字典 / 列表）。

    配套**课堂练习 2**：解析 JSON 字符串并取出 `name` 字段。

- **`json.dumps(Python对象)`**

    功能：将 Python 对象转为**JSON 字符串**；
    text = json.dumps(data, ensure_ascii=False)

    常用参数：`ensure_ascii=False` 解决中文乱码，`indent=数字` 实现格式化缩进。

- **`json.load(文件对象)`**
    data = json.load(f)
    功能：从**本地 JSON 文件**读取数据，转为 Python 对象。

- **`json.dump(Python对象, 文件对象)`**
    json.dump(data, f, ensure_ascii=False)
    功能：将 Python 对象写入**本地 JSON 文件**，支持中文与格式化参数。
