## Supervised Learning（监督学习）

**定义**：从输入 $X$ 映射到输出 $Y$，训练数据是一组配对样本 $(x^{(i)}, y^{(i)})$。

- **回归问题（Regression）**：输出 $y$ 是**连续值**（例：房价预测）
- **分类问题（Classification）**：输出 $y$ 是**离散值**（后面课程讲）
- 设计一个学习算法的三个关键决策：
  1. 怎么**表示假设**（Hypothesis）
  2. 用什么**数据集**
  3. 怎么**学习参数**

### 符号约定（整门课通用）

| 符号 | 含义 |
|------|------|
| $\theta$ | 参数（Parameters），学习算法的输出 |
| $m$ | 训练样本个数 |
| $n$ | 特征个数（$\theta$、$x$ 为 $n+1$ 维，含 $\theta_0$ 和 $x_0$） |
| $x^{(i)}$ | 第 $i$ 个样本的输入特征向量（上标 $^{(i)}$ 是样本索引） |
| $y^{(i)}$ | 第 $i$ 个样本的真实输出（目标值） |

## 回归模型（线性回归）

### 1. 假设函数 Hypothesis

$$
h_\theta(x) = \theta_0 + \theta_1 x_1 + \theta_2 x_2 = \sum_{j=0}^{n} \theta_j x_j
$$

- 引入**虚拟特征** $x_0 \equiv 1$，方便统一成向量内积 $h_\theta(x) = \theta^T x$
- 严格说是**仿射函数（Affine Function）**而非纯线性函数
- 例：房价预测，$x_1$=面积，$x_2$=卧室数

### 2. 代价函数 Cost Function

$$
J(\theta) = \frac{1}{2} \sum_{i=1}^{m} \left( h_\theta(x^{(i)}) - y^{(i)} \right)^2
$$

- 系数 $\frac{1}{2}$：纯数学方便（求导时平方项的 2 被抵消）
- 目标：找到 $\theta$ 使 $J(\theta)$ **最小**
- **为什么用平方误差**：本讲留悬念，后面讲 GLM（广义线性模型）时证明——平方误差对应高斯分布假设
- 关键性质：$J(\theta)$ 是**凸二次函数**（等值线为椭圆），**只有全局最优、没有局部最优** → 梯度下降保证收敛

### 3. 梯度下降 Gradient Descent（核心）

**思路**：从初始 $\theta$（随机或全 0）出发，沿代价函数**最陡下坡方向**（负梯度）逐步迭代至谷底。

**更新规则**（对所有 $j = 0 \dots n$ **同步**更新）：

$$
\theta_j := \theta_j - \alpha \frac{\partial}{\partial \theta_j} J(\theta)
$$

**用链式法则求偏导**，得到具体形式：

$$
\frac{\partial J}{\partial \theta_j} = \sum_{i=1}^{m} \left( h_\theta(x^{(i)}) - y^{(i)} \right) x_j^{(i)}
$$

**学习率 $\alpha$（步长）怎么选**：
- 太大 → 一步跨过谷底，震荡甚至发散（发散时 $J(\theta)$ 反而增大）
- 太小 → 收敛极慢
- 经验值：初始 $\alpha = 0.01$，在**指数尺度**上尝试（0.1、0.2、0.4…），观察 $J(\theta)$ 下降曲线
- 若特征缩放到 $[0,1]$ 或 $[-1,1]$，更容易找到合适的 $\alpha$

**收敛监控**：画 $J(\theta)$ 随迭代次数的曲线，不再显著下降即可停止训练。

### 4. 批量梯度下降 vs 随机梯度下降

| 维度     | 批量 GD（Batch）   | 随机 SGD（Stochastic）      |
| ------ | -------------- | ----------------------- |
| 每步看的数据 | **全部 $m$ 个样本** | **1 个样本**               |
| 收敛行为   | 精确收敛到全局最优      | 路径带噪声，**不彻底收敛**，但平均朝最优走 |
| 速度     | 大数据集每步极慢       | 大数据集快得多，**现代 ML 主流**    |
| 适用场景   | 几百~几千样本的小数据集   | 海量（TB 级）数据              |
| 技巧     | —              | 学习率**随时间递减**可减小震荡       |

> 补充：线性回归无局部最优问题，收敛调试比神经网络简单；SGD 虽不完全收敛，所得参数用于预测效果已足够好。

### 5. 正规方程 Normal Equation（闭式解）

线性回归特有的**一步到位**解法，无需迭代：

1. 定义**设计矩阵** $X$（$m \times (n+1)$，每行一个样本）和标签向量 $y$
2. 代价函数写成矩阵形式：$J(\theta) = \frac{1}{2} (X\theta - y)^T (X\theta - y)$
3. 用**矩阵导数记号**与**迹运算性质**（如 $\mathrm{Tr}(AB) = \mathrm{Tr}(BA)$）求导并令其为 0：

$$
X^T X \theta = X^T y
$$

$$
\theta = (X^T X)^{-1} X^T y
$$

- 若 $X^T X$ **不可逆**：说明特征**冗余/线性相关**（如两个特征完全成比例），用**伪逆（Pseudo-inverse）**仍可求解


### 矩阵迹求导 $\nabla_A \operatorname{tr}(A A^\top C) = CA + C^\top A$
符号说明：
- $\nabla_A$：对矩阵$A$求梯度，结果和$A$同尺寸矩阵
- $\operatorname{tr}(\cdot)$：迹，方阵对角线元素之和

迹轮换性质：$\operatorname{tr}(XYZ)=\operatorname{tr}(YZX)$
推导：
$$
\begin{align*}
\nabla_A \operatorname{tr}(A A^\top C)
&=\nabla_A\operatorname{tr}(A^\top C A) \\
&= CA + C^\top A
\end{align*}
$$
> 记忆口诀：分别对两处A求导，两项相加。
> 考点：矩阵求导不满足普通标量交换顺序，顺序不能随便调换！

## 小结

```
问题设定(监督学习) → 假设函数 h_θ(x) → 代价函数 J(θ) → 求解
                                     ├─ 梯度下降（迭代，通用）：批量GD / 随机GD
                                     └─ 正规方程（闭式解，线性回归专属）
```

- 梯度下降是**所有后续模型**（逻辑回归、神经网络、SVM 等）共同的训练引擎，务必吃透
- 本讲为整门课的地基：符号体系、代价函数、优化思路贯穿后续所有章节
