## 1. SVM 回顾：大间隔分类器

### 1.1 从逻辑回归到SVM

逻辑回归的假设函数：
$$h_\theta(x) = \frac{1}{1+e^{-\theta^Tx}}$$

- 当 $y=1$ 时，我们希望 $\theta^Tx \gg 0$（置信度高）
- 当 $y=0$ 时，我们希望 $\theta^Tx \ll 0$

SVM 替换了逻辑回归的对数代价函数，采用分段的 `cost₁(z)` 和 `cost₀(z)`：
- $y=1$ 时：不仅要求 $\theta^Tx \ge 0$，更进一步要求 $\theta^Tx \ge 1$
- $y=0$ 时：不仅要求 $\theta^Tx < 0$，更进一步要求 $\theta^Tx \le -1$

这相当于在分类器中加入了**安全间隔（margin）**。

### 1.2 SVM 优化目标

$$\min_\theta \; C \sum_{i=1}^m \left[ y^{(i)} cost_1(\theta^Tx^{(i)}) + (1-y^{(i)}) cost_0(\theta^Tx^{(i)}) \right] + \frac{1}{2}\sum_{j=1}^n \theta_j^2$$

与逻辑回归的对应关系：
- 逻辑回归：$A + \lambda B$
- SVM：$CA + B$，其中 $C = 1/\lambda$

### 1.3 大间隔直觉

- 参数 $C$ 很大时：SVM 会尽可能将所有样本正确分类，对异常点敏感
- 参数 $C$ 较小时：允许一些误分类，决策边界更鲁棒

SVM 会选择离最近样本点最远的决策边界，即**最大化几何间隔**。

## 2. 向量内积与几何意义

### 2.1 内积定义

对于向量 $u, v \in \mathbb{R}^n$：
$$u^Tv = \|u\| \cdot p$$

其中 $p$ 是 $v$ 在 $u$ 方向上的投影长度。
- 夹角 < 90°：$p > 0$
- 夹角 > 90°：$p < 0$

### 2.2 简化形式下的SVM

令 $\theta_0 = 0$，SVM 优化问题可写为：

$$\min_\theta \frac{1}{2}\|\theta\|^2$$
$$\text{s.t. } p^{(i)} \cdot \|\theta\| \ge 1 \quad \text{if } y^{(i)}=1$$
$$\text{s.t. } p^{(i)} \cdot \|\theta\| \le -1 \quad \text{if } y^{(i)}=0$$

其中 $p^{(i)}$ 是 $x^{(i)}$ 在 $\theta$ 方向上的投影。

最小化 $\|\theta\|$ 等价于最大化样本点到决策边界的几何间隔。

## 3. SVM 对偶形式推导

### 3.1 原始问题（Primal）

硬间隔SVM的原始优化问题：

$$\min_{w,b} \frac{1}{2}\|w\|^2$$
$$\text{s.t. } y^{(i)}(w^Tx^{(i)} + b) \ge 1, \quad i=1,...,m$$

> 注：约束将函数间隔固定为1，此时几何间隔 = $1/\|w\|$，最小化 $\|w\|^2$ 即最大化几何间隔。

### 3.2 构建拉格朗日函数

将约束改写为 $g_i(w,b) = 1 - y^{(i)}(w^Tx^{(i)}+b) \le 0$，拉格朗日函数：

$$\mathcal{L}(w,b,\alpha) = \frac{1}{2}\|w\|^2 - \sum_{i=1}^m \alpha_i \left[ y^{(i)}(w^Tx^{(i)}+b) - 1 \right]$$

其中 $\alpha_i \ge 0$ 是拉格朗日乘子。

### 3.3 对原始变量求偏导并置零

**对 $w$ 求导：**
$$\nabla_w \mathcal{L} = w - \sum_{i=1}^m \alpha_i y^{(i)} x^{(i)} = 0$$
$$\Rightarrow w = \sum_{i=1}^m \alpha_i y^{(i)} x^{(i)}$$

> 重要结论：最优权重向量 $w$ 是训练样本的线性组合，系数为 $\alpha_i y^{(i)}$。$\alpha_i = 0$ 的样本对 $w$ 没有贡献。

**对 $b$ 求导：**
$$\frac{\partial \mathcal{L}}{\partial b} = -\sum_{i=1}^m \alpha_i y^{(i)} = 0$$
$$\Rightarrow \sum_{i=1}^m \alpha_i y^{(i)} = 0$$

### 3.4 代回得到对偶函数

将 $w = \sum_i \alpha_i y^{(i)} x^{(i)}$ 和 $\sum_i \alpha_i y^{(i)} = 0$ 代回拉格朗日函数，化简后得到：

$$\theta_\mathcal{D}(\alpha) = \sum_{i=1}^m \alpha_i - \frac{1}{2}\sum_{i=1}^m\sum_{j=1}^m \alpha_i \alpha_j y^{(i)} y^{(j)} \langle x^{(i)}, x^{(j)} \rangle$$

### 3.5 对偶优化问题（Dual）

$$\max_\alpha \sum_{i=1}^m \alpha_i - \frac{1}{2}\sum_{i,j} \alpha_i \alpha_j y^{(i)} y^{(j)} \langle x^{(i)}, x^{(j)} \rangle$$

约束条件：
- $\alpha_i \ge 0, \quad i=1,...,m$
- $\sum_{i=1}^m \alpha_i y^{(i)} = 0$

## 4. KKT 条件与支持向量

### 4.1 KKT 四个条件

1. **稳定性条件**：拉格朗日对 $w, b$ 的梯度为零（已用于推导）
2. **原始可行性**：$y^{(i)}(w^Tx^{(i)}+b) \ge 1$ 对所有 $i$ 成立
3. **对偶可行性**：$\alpha_i \ge 0$ 对所有 $i$ 成立
4. **互补松弛条件**：$\alpha_i \left[ y^{(i)}(w^Tx^{(i)}+b) - 1 \right] = 0$

### 4.2 支持向量的定义

由互补松弛条件可知，对于每个训练样本：
- 要么 $\alpha_i = 0$ → 该样本不影响 $w$，**不是支持向量**
- 要么 $y^{(i)}(w^Tx^{(i)}+b) = 1$ → 样本恰好位于间隔边界上，**是支持向量**

只有 $\alpha_i > 0$ 的样本才是支持向量，它们决定了决策边界。

### 4.3 恢复偏置 $b$

任选一个支持向量 $i^*$（$\alpha_{i^*} > 0$），利用：
$$y^{(i^*)}(w^Tx^{(i^*)} + b) = 1$$
$$\Rightarrow b = y^{(i^*)} - w^Tx^{(i^*)}$$

实际应用中通常对所有支持向量的 $b$ 取平均以提高数值稳定性。

## 5. 核技巧（Kernel Trick）

### 5.1 为什么需要核技巧

观察对偶目标函数：
$$\sum_{i,j} \alpha_i \alpha_j y^{(i)} y^{(j)} \langle x^{(i)}, x^{(j)} \rangle$$

**特征 $x^{(i)}$ 只以内积 $\langle x^{(i)}, x^{(j)} \rangle$ 的形式出现**，从不单独出现。

这意味着：如果我们想把数据映射到高维空间 $\phi(x)$ 以学习非线性边界，我们**永远不需要显式计算 $\phi(x)$**，只需要一个函数直接返回映射后的内积：

$$K(x, z) = \langle \phi(x), \phi(z) \rangle = \phi(x)^T \phi(z)$$

这个函数 $K$ 就叫做**核函数**。

### 5.2 核技巧的核心思想

> 把对偶问题中所有的内积 $\langle x^{(i)}, x^{(j)} \rangle$ 替换为核函数 $K(x^{(i)}, x^{(j)})$，就隐式地将数据映射到了高维特征空间，而不需要付出高维计算的代价。

最终分类器变为：
$$f(x) = \text{sign}\left( \sum_{i=1}^m \alpha_i y^{(i)} K(x^{(i)}, x) + b \right)$$

## 6. 常见核函数

### 6.1 线性核

$$K(x, z) = x^T z$$

就是原始内积，相当于不做特征映射。适用于特征维度已经很高、样本量很大的场景。

### 6.2 多项式核

$$K(x, z) = (x^T z + c)^d$$

对应将特征映射到所有 $d$ 阶多项式组合的空间。例如 $d=2, c=1$ 时，2维输入映射到6维空间（包含交叉项 $x_1x_2, x_1^2, x_2^2$ 等）。

### 6.3 高斯核（RBF核）

$$K(x, z) = \exp\left( -\frac{\|x - z\|^2}{2\sigma^2} \right)$$

- 也称为径向基函数（Radial Basis Function）核
- 对应一个**无限维**的特征映射 $\phi(x)$
- 衡量样本点 $x$ 与锚点 $z$ 之间的相似度：距离越近，核值越接近1；距离越远，核值越接近0
- $\sigma$ 是带宽参数，控制高斯函数的"宽度"

> 直观理解：高斯核SVM相当于在每个训练样本 $x^{(i)}$ 处放置一个高斯钟形函数，最终决策面是这些钟形函数的加权叠加。

## 7. Mercer 定理

### 7.1 核的有效性判定

给定函数 $K: \mathbb{R}^d \times \mathbb{R}^d \to \mathbb{R}$，$K$ 是合法核（Mercer核）的充要条件是：

> 对于任意有限个样本 $\{x^{(1)}, ..., x^{(m)}\}$，对应的核矩阵 $K_{ij} = K(x^{(i)}, x^{(j)})$ 是**对称半正定矩阵**。

### 7.2 意义

Mercer 定理告诉我们：不需要找到对应的特征映射 $\phi$，只需要检查核矩阵是否半正定，就能判断一个函数能否作为核使用。这极大地扩展了核函数的设计空间。

## 8. 软间隔SVM（Soft Margin）

### 8.1 动机

硬间隔SVM要求数据完全线性可分，对噪声和异常点非常敏感。软间隔引入松弛变量 $\xi_i$ 允许一些样本违反间隔约束：

$$\min_{w,b,\xi} \frac{1}{2}\|w\|^2 + C \sum_{i=1}^m \xi_i$$
$$\text{s.t. } y^{(i)}(w^Tx^{(i)}+b) \ge 1 - \xi_i, \quad \xi_i \ge 0$$

### 8.2 软间隔对偶

对偶目标函数形式不变，唯一区别是约束增加了上界：

$$0 \le \alpha_i \le C$$

原来的 $\alpha_i \ge 0$ 变成了 $0 \le \alpha_i \le C$，这就是所谓的**箱型约束（box constraint）**。

参数 $C$ 的含义：
- $C$ 越大：对误分类惩罚越重，越接近硬间隔
- $C$ 越小：允许更多误分类，决策边界更平滑，正则化更强

## 9. 本课关键要点总结

| 概念 | 核心要点 |
|------|----------|
| 大间隔分类器 | 最大化样本到决策边界的距离，比逻辑回归更鲁棒 |
| 对偶形式 | 原始问题通过拉格朗日对偶转化为关于 $\alpha$ 的优化问题 |
| 支持向量 | 只有 $\alpha_i > 0$ 的样本决定决策边界，其余样本无影响 |
| 核技巧 | 将内积替换为核函数，隐式映射到高维空间，不显式计算 $\phi(x)$ |
| 高斯核 | 最常用的核函数，对应无限维特征空间，衡量样本间相似度 |
| Mercer定理 | 核矩阵半正定是核函数合法的充要条件 |
| 软间隔 | 通过松弛变量和参数 $C$ 允许误分类，处理非线性可分数据 |

---

## 10. 为什么对偶形式如此重要？

1. **核技巧成为可能**：对偶问题中数据只通过内积出现，才能用核函数替换
2. **维度无关**：对偶问题的变量数等于样本数 $m$，与特征维度无关。即使映射到无限维（RBF核），优化仍然是有限维的
3. **稀疏性**：大部分 $\alpha_i = 0$，只有少数支持向量起作用，预测效率高
4. **通用方法论**：拉格朗日对偶是机器学习中的通用工具，后续在高斯过程、正则化等主题中还会反复出现
