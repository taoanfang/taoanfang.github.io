Machine Learning

CS229

Machine Learning

以 Stanford CS229 2018 课程为主线的机器学习笔记，覆盖监督学习、广义线性模型、生成学习、支持向量机、核方法与 Softmax 回归。

7 篇笔记 14 分钟

监督学习基础

01 线性回归与梯度下降 监督学习基本框架、线性回归、批量与随机梯度下降、正规方程。 2 分钟 02 局部加权与逻辑回归 LWR、线性回归的概率解释、逻辑回归与牛顿法。 2 分钟 03 感知机与广义线性模型 感知机、指数族、GLM 的构造与 Softmax 概览。 2 分钟 04 Softmax 回归 从 GLM 推导多分类模型，讨论损失、梯度和数值实现。 2 分钟 05 GDA 与朴素贝叶斯 生成学习、多元高斯、高斯判别分析、朴素贝叶斯与 Laplace 平滑。 2 分钟

间隔、对偶与核方法

06 支持向量机 函数间隔、几何间隔、最优间隔分类器、拉格朗日对偶与 KKT。 2 分钟 07 核方法与 SVM 对偶 核技巧、常见核函数、Mercer 定理与软间隔 SVM。 2 分钟
