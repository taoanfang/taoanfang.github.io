Selected Project

DeepSeek-OCR Reproduction

Independent systems project

2026

Built a lightweight DeepSeek-OCR-style pipeline on an 8GB laptop GPU, then designed diagnostics to explain why the trained model learned document-style priors instead of reading the page.

  • Constructed a 428M SigLIP encoder, convolutional visual compressor, projection layer, and Qwen2.5 decoder pipeline with two-stage LoRA training.
  • Trained on 5,393 olmOCR pages and evaluated against OmniDocBench without using the benchmark in training.
  • Found that both 256-token and 1024-token visual budgets produced page-level template collapse, pointing to the frozen encoder and loss of temporal character alignment rather than token count alone.
  • Compared Qwen2.5-0.5B and 1.5B, soft CTC OCR tokens, hybrid text-plus-soft-token inputs, and formula oversampling on rented GPUs.
