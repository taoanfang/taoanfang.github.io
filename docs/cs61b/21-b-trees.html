B-Tree

miuzxc

一、前置知识：BST 树高与渐近符号 Big O / Big Θ

1. BST 两种极端形态

  1. 瘦长树（spindly，最坏情况） 顺序插入 1,2,3,4,5,6,7，树退化成链表，树高 (\Theta(N))，contains/add 耗时 (\Theta(N))。
  2. 矮胖树（bushy，最好情况） 随机 / 均衡插入，树高 (\Theta(\log N))，操作耗时 (\Theta(\log N))。
  3. 现实痛点：业务数据经常有序（时间、日期），无法保证随机插入，BST 极易退化。

2. Big O vs Big Θ 核心区别

  • (\Theta(X))：精确描述增长阶，等于 X；信息更精准。
  • (O(X))：仅描述上界，增长速度不会超过 X；范围更宽泛。

举例对比

  1. 「BST 最坏树高 (\Theta(N))」= 精确说明最差就是线性高度
  2. 「BST 树高 (O(N))」= 所有树高度都不超过线性，包含最优、平均、最差
  3. 「BST 树高 (O(N^2))」也成立，但完全没有参考价值。

通俗类比

  • (\Theta(N))：酒店最贵房间 639 元（精准上限）
  • (O(N))：酒店所有房间≤639 元（宽泛约束） 精准的 Θ 描述信息量远大于宽泛的 O 描述。

3. 随机插入 BST 特性

  • 随机插入数据，树的平均深度、期望高度均为 (\Theta(\log N))；
  • 带删除操作时，只要删除时随机选前驱 / 后继，依旧保持 (\Theta(\log N)) 高度。

4. 节点深度 & 树高定义

  • 节点深度：节点距离根节点的层数（根深度 = 0）
  • 树高度：最深叶子的深度；决定单次查找最坏比较次数
  • 平均深度：所有节点深度平均值，决定查找平均耗时

二、B 树核心设计思路：彻底解决 BST 失衡

1. 原始优化构想：不新增底层叶子

普通 BST 失衡根源：每次新增节点都放在最底层，树越插越深。 B 树思路：新数据不生成新叶子，直接塞进现有叶子节点，永远不增加树的高度。 缺点：叶子节点会存放大量数据（课称 “多汁节点 juicy node”），节点内遍历变慢。

2. 解决方案：节点分裂 Split

  1. 设定上限 L：单个节点最多存放 L 个键；
  2. 插入后超量时执行分裂：
    • 取出节点中间键，上移给父节点；
    • 剩余键拆分为左右两个新节点，作为父节点新子节点；
  3. 节点内仅存少量数据，单次对比开销是常数，不影响整体复杂度。

3. 连锁分裂（Chain Reaction Splitting）

分裂后父节点新增键，若父节点也超出容量上限，继续向上分裂； 特殊场景：根节点满了需要分裂

  • 中间键单独生成新根；
  • 原节点拆分为左右两棵子树；
  • 整棵树高度 + 1，所有叶子同步下沉一层，深度依旧完全相等。

4. 实操示例：2-3 树插入有序数字 1,2,3,4,5,6,7

普通 BST 会变成一条链；2-3 树全程平衡，所有叶子深度完全一致。 无论何种插入顺序，B 树都能维持矮胖形态，不会出现瘦长退化。

三、B 树两大强制不变量（Invariants）

这两条规则保证树永久平衡：

  1. 所有叶子节点到根的距离完全相同，不存在深浅不一的叶子；
  2. 非叶子节点存储 k 个键，则一定拥有 (k+1) 个子节点； 例：节点存 2 个键，必须有 3 条分叉子树。

违反任意一条的树都不属于合法 B 树。

四、B 树专业术语

1. 按节点容量分类

  1. 2-3 树（L=2） 单个节点最多存 2 个键，最多 3 个子节点；
  2. 2-3-4 树 / 2-4 树（L=3） 单个节点最多存 3 个键，最多 4 个子节点；

2. 两种应用场景

  1. 教学场景：L=2/3（2-3、2-3-4 树），逻辑简单，用于理解平衡树；
  2. 工程场景：L 取数千，数据库、文件系统底层存储结构。

补充

B-tree 的 B 无官方定义，普遍认为代表 Balanced（平衡）、Bayer（发明者）。

五、B 树时间复杂度分析

参数说明：

  • L：单节点最大键数量（常数）
  • H：树高度，恒为 (\Theta(\log N))
  1. contains 查找 逐层向下遍历节点，每层最多对比 L 个键；总复杂度 (O(L\log N) = O(\log N))。
  2. add 插入 向下查找叶子 + 插入节点 + 最坏连锁分裂至根；分裂次数最多等于树高；总复杂度 (O(\log N))。

树高范围

  • 最优高度：全部节点填满 L 个键，高度 (\log_{L+1}N)
  • 最差高度：所有节点仅存 1 个键，高度 (\log_{2}N) 整体高度稳定为对数级别。
