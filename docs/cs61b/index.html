Data Structures

CS61B

Java 与数据结构

从 Java 面向对象、泛型与集合出发，进入复杂度分析、链表、树结构与算法设计。现有笔记来自 Java、数据结构与算法目录，按 CS61B 学习路径重新编排。

20 篇笔记 32 分钟

Java 语言基础

01 Java 面向对象与封装 类、对象、构造方法、访问控制、this 与 static。 2 分钟 02 继承、抽象类与接口 继承关系、方法重写、super、final、抽象类和接口的职责边界。 2 分钟 03 多态与内部类 静态与动态多态、向上向下转型、Object 类和四种内部类。 1 分钟 04 Java 泛型 泛型类、泛型接口和类型参数的基本用法。 1 分钟 05 Java API：字符串、包装类与正则 String、StringBuffer、包装类以及正则表达式校验。 1 分钟 06 集合与迭代器 List、Set、增强 for 循环与 Iterator 之间的关系。 1 分钟 07 异常处理 异常体系、捕获与声明，以及课堂中的关键图示。 1 分钟 08 文件与 IO 流 File、字节流、字符流与转换流。 2 分钟 09 多线程 线程生命周期、创建方式、同步、锁与并发安全。 3 分钟 10 网络编程 TCP/IP、Socket、UDP 与多线程网络通信。 3 分钟

数据结构基础

11 ADT 与算法基础 抽象数据类型、算法五要素以及如何从复杂度开始阅读算法。 1 分钟 12 线性表 线性表的类型定义、顺序实现与链式表达。 1 分钟 13 栈与队列 栈和队列的抽象结构与使用场景。 1 分钟 14 链表与递归数据结构 SLL、递归结构、哨兵节点和空指针处理。 1 分钟 15 双向链表与动态数组 从单链表到双向链表，以及数组扩容的摊销思路。 1 分钟 16 泛型集合入门 用 List 和泛型组织一组同类型数据。 1 分钟 17 多态、Comparable 与 Comparator 亚型多态、参数化多态以及两套比较器接口。 2 分钟 18 增长阶与并查集 Big-O、Big-Theta、Quick Find、Quick Union、按秩合并与路径压缩。 2 分钟

复杂度与树结构

19 二叉搜索树 BST 定义、查找路径、插入删除与复杂度。 2 分钟 20 B 树 从 BST 退化问题进入平衡树与 B 树结构。 3 分钟
