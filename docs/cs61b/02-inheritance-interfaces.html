继承、抽象类与接口

继承关系、方法重写、super、final、抽象类和接口的职责边界。

2 分钟 第 2 / 20 篇

继承（extends）

子类（class）：新的

可以调用父类中的方法，属性

子类可以定义私有属性

只允许单继承，不允许多继承，也就是说一个类只能有一个父亲，但一个父亲可以有多个孩子

父类（class）旧的

方法的重写

变量名字，类型，参数列表，返回值均得一致

子类重写父类方法时，不能使用比父类方法要求更严格的权限 私有方法，静态方法不能被重写

super关键字

super.父类的属性

super.父类的方法(参数1,参数2…)

final关键字（不可改变，final关键字可以修饰变量、方法和类）（无子类）

抽象类和接口

抽象类（abstract）修饰成员方法，不可以使用private修饰

访问修饰符 abstract 返回值类型 方法名称(参数列表);

由抽象方法的类叫~

抽象类不能直接创建对象

接口：为了克服单继承的限制（找爹）

[public] interface 接口名 [extends 接口1,接口2...] { [public] [static] [final] 数据类型 常量名 = 常量; [public] [abstract] 返回值的数据类型 方法名(参数列表); [public] static 返回值的数据类型 方法名(参数列表){} [public] default 返回值的数据类型 方法名(参数列表){} } 接口的存在，为了实现，而不是继承

本身不能实例化，通过implements关键字实现接口，并且实现类必须重写接口中所有的抽象方法

  • 访问权限：默认是public（即使不写，也强制为 public），不能定义为 private/protected/ 默认权限（编译报错）。
  • 抽象性：默认是abstract（无需手动写abstract关键字），没有方法体（即没有{} 和具体代码），以分号结尾。
  • 方法签名：仅包含返回值类型、方法名、参数列表，必须由实现类（通过 implements实现接口的类）重写（Override）。
