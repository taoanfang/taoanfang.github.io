多态与内部类

静态与动态多态、向上向下转型、Object 类和四种内部类。

1 分钟 第 3 / 20 篇

多态（静态，动态）

静态多态（编译时）：重载

动态多态（运行时）重写

对象向上转型：父类对象调用子类重写父类的方法

对象向下转型：向下转型一般是为了重新获得因为向上转型而丢失的子类特性。对象在进行的向下转型前，必须先进行向上转型，这样可以确保引用变量所引用的对象属于子类，不能将父类实例强制转换为子类实例

instance of关键字（object instance of type->T/F）

内部类

成员内部类：成员内部类可以访问外部类的所有成员变量和方法

局部内部类：局部内部类可以访问外部类的所有成员变量和方法，而局部内部类中变量和方法只能在局部内部类所在的方法中被访问。避免代码污染，临时复用

静态内部类：只能访问外部类的静态成员，通过外部类访问静态内部类的成员时，可以跳过外部类直接访问

匿名内部类：直接用（）
