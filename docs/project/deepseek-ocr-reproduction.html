Independent systems project

When the model learned the page style, but not the page.

Built a lightweight DeepSeek-OCR-style pipeline on an 8GB laptop GPU, then designed diagnostics to explain why the trained model learned document-style priors instead of reading the page.

5,393 training pages
8 GB local GPU budget
0.5B / 1.5B decoder ablations
256 / 1024 visual-token budgets

My roleIndependent implementation, training, evaluation, failure analysis, and technical reporting.

Project typePaper reproduction and diagnostic study. This is not a claim of a novel OCR model.

Question

Where does visual information disappear?

DeepSeek-OCR motivated a simple question: can a page image be compressed into a small number of visual tokens and decoded into Markdown by a compact language model? I wanted to reproduce the core architecture under a much smaller budget, then determine whether failures came from token compression, the frozen vision encoder, the language decoder, or the evaluation protocol.

System

A complete pipeline, small enough to inspect.

01Document page896 × 896 image
02SigLIP encoderfrozen vision features
03Conv compressor256 / 1024 visual tokens
04Qwen2.5 + LoRAdocument to Markdown

The first stage trained the visual connector and projection layer. The second stage added LoRA adapters to Qwen2.5-0.5B or Qwen2.5-1.5B. The local experiments used an 8GB RTX 5060 Laptop GPU; larger decoder, hybrid-input, and formula experiments used rented GPUs.

Diagnosis

The training loss looked plausible. The model was not reading the image.

Aggregate validation loss was misleading. The generated Markdown was fluent, but pages with different content received nearly identical outputs. I combined four diagnostics:

  • First-token loss: with no text prefix available, the model could not identify the first character from the image.
  • Cross-page similarity: compressed visual features became so similar that different pages were almost indistinguishable.
  • Self-retrieval: outputs were not more similar to their source page than to other pages.
  • Linear probes: character identity was preserved in the temporal OCR sequence but disappeared after pooling and cross-modal projection.
The most useful result was not a higher score. It was evidence that the model had learned a document-style prior while the image-to-text path remained effectively disconnected.

Experiments

Changing the obvious variable did not fix the failure.

I compared visual-token budgets, decoder sizes, soft CTC OCR tokens, hybrid text-plus-soft-token inputs, and formula-page oversampling. Increasing the visual budget from 256 to 1024 tokens did not produce page-specific text. A larger decoder and explicit OCR context improved accuracy, but did not remove the information bottleneck.

Takeaway

What this project changed in how I work.

  • I now treat a fluent generated example as a hypothesis, not evidence that a model uses its input.
  • I design negative controls before spending time on larger models or longer training.
  • I document failed experiments and their boundary conditions so that the next decision is based on evidence.
  • I learned that a well-explained failure can be more informative than an untrustworthy improvement.

Limitations

What this study does not establish.

The main evaluations use small fixed subsets of 20 or 50 pages, and some comparisons were run with a single seed. The results are useful for engineering decisions and failure diagnosis, but they are not a statistically complete benchmark study. The project is a reproduction and analysis, not peer-reviewed research.
