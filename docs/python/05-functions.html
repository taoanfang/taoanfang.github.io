可变默认参数陷阱：

关键字参数与位置参数联合使用： *：收集额外的位置参数，返回元组 * *：kwargs：放入字典 'def print_info(**kwargs): print(kwargs) # {'name': 'Alice', 'age': 20}

*args:收集多余的位置参数，封装为元组 def print_numbers(*args): print(args) # (1, 2, 3)

locals（）：可用于查看当前局部作用域中的名字和值，返回一个字典 globals（）：可用于查看当前全局作用域中的名字和值，返回一个字典 vars（）：在不带参数时，通常可看作与 locals() 类似；带参数时，用于返回对象的属性字典。

常用高阶函数

  1. map(func, iterable)

    • 将函数依次作用于可迭代对象的每个元素，返回迭代器
    • Python 3 需用 list() 转换为列表
    • 多数场景可被列表推导式替代，可读性更好

  2. filter(func, iterable)

    • 保留使函数返回 True 的元素，返回迭代器
    • 同样优先推荐使用列表推导式的条件筛选

  3. reduce(func, iterable)

    • 从 functools 模块导入，逐次合并序列元素，最终得到单个结果
    • 复杂逻辑下可读性差，通常优先改用普通循环实现
